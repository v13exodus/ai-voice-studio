## About The Project

This application empowers creators to generate professional-grade voice-overs with unparalleled creative control. Instead of relying on static, robotic voices, users can act as a voice director—describing the precise age, gender, accent, and emotional tone they need. The AI then interprets this creative direction to produce a nuanced, authentic, and studio-quality audio performance, ready for any project.

This project was built to provide an intuitive, powerful, and cost-effective solution for YouTubers, marketers, educators, and any creator who needs high-quality voice audio without the complexities of traditional recording.

## Key Features

*   **🎬 Creative Voice Direction:** Specify accent, age, gender, pitch, speed, and emotional tone.
*   **🌍 Global Language Support:** Generate voice-overs in dozens of languages with authentic-sounding accents.
*   **🤖 AI-Powered Prompt Refinement:** The app intelligently refines your creative description into an optimal prompt for the AI.
*   **💎 Glamorous & Intuitive UI:** A beautiful, easy-to-use interface that makes the creation process a pleasure.
*   **💾 Production-Ready Output:** Instantly download your generated audio as a high-quality `.wav` file.
*   **🔒 Secure & Scalable:** Built with a serverless backend to protect API keys and ensure reliable performance.

## Built With

This project is a modern web application built with a focus on great user experience and a secure architecture.

*   **Frontend:** [React](https://reactjs.org/) & [TypeScript](https://www.typescriptlang.org/)
*   **Backend:** Serverless Functions (deployed on Vercel)
*   **Styling:** Custom CSS with a dynamic and responsive design
